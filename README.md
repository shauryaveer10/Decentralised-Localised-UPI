
# Decentralised Localised UPI

A project exploring decentralised and location-aware digital payments using India's Unified Payments Interface (UPI).

## Overview

**Decentralised Localised UPI** aims to explore how digital payment systems can incorporate decentralised architecture and location-based context to support more flexible, accessible, and locally relevant payment experiences.

The project focuses on the intersection of digital payments, decentralised systems, and location-aware services, with the goal of investigating alternative approaches to conventional payment workflows.

## Objectives

- **Decentralisation:** Explore architectural approaches that reduce reliance on a single central component.
- **Location Awareness:** Investigate how geographical context can be incorporated into payment workflows.
- **UPI Integration:** Explore how the system could interact with India's UPI ecosystem.
- **Security and Reliability:** Consider authentication, transaction integrity, and secure handling of payment-related information.
- **Scalability:** Design with maintainability and future expansion in mind.
